# 游戏素材与临时行为

网页直接消费本地另行提供的素材包，接入方式见 [开发说明](./development.md#素材打包)。资源准备脚本不修改素材包。输出为 Git 忽略的 `public/game/`，包含 `catalog.json`、`content.json`、裁剪后的 WOFF2 字体、内容哈希命名的 WebP 图集及音频。重复运行会删除不再引用的旧素材；来源映射写入 `.runtime/game-sources.json`。

## 已验证的素材接入

- 12 个角色、61 段动画来自透明 PNG 和逐图层关键帧；主图层与 Body 上层同时播放，隐藏帧会隐藏对应图层。角色根位置归零，保留子节点位置、缩放、pivot 和排序。
- 大厅采用现有七层 Tilemap 中有效的精灵引用，保留网格、锚点、变换矩阵、颜色和顺序；非 Tilemap 的可见精灵亦来自交付。没有将所有有贴图的格子标为障碍。
- 地图采用 Challenge10 的 15 个游戏对象与原布局。平台暂按可视尺寸建立矩形碰撞，并非精确碰撞网格。
- 大厅使用已导出 BoxCollider2D 与 CompositeCollider2D 轮廓。复合轮廓坐标包含网格缩放，仅添加节点偏移；精度仍待核验。
- 引用文件均保留原路径到网页 URL 的映射。长资源 ID 始终使用字符串。交付 JSON 中字符串外的 `NaN`/`Infinity` 被规范化为 `null`，无效颜色回退为白色并输出来源计数；非法几何或矩阵会明确报错。

## 集中维护的规则

参数唯一入口是 `shared/game-behavior.ts`；`shared/game-rope.ts` 单独实现绳索力。网络坐标采用源场景单位、X 向右、Y 向上；仅在物理内部除以 100，渲染时反转 Y。权威模拟固定每秒 60 步，模拟代码集中在 `shared/world.ts`，服务器与浏览器共用。

## 网络同步

服务器仍是唯一权威：客户端只发送输入，不上报坐标，钥匙、星星、开门和通关只由服务器判定。浏览器按 60 Hz 固定步长采样输入，每步发送一条带递增序号的输入，同时用同一份模拟代码立即推进自己的小猫（本地预测）。服务器每个物理步消费队列中的一条输入，队列超过 6 条时合并最旧的输入以免积压成延迟，合并时保留跳跃按下；每份 20 Hz 快照附带接收方最后一条已模拟输入的序号 `ack`。浏览器收到快照后回到服务器状态，重放尚未确认的输入；新旧预测的差值在约 0.1 秒内渐隐，超过 400 单位（如复活传送）直接跳到新位置。

其他玩家在预测世界中是运动学代理，只提供碰撞，不模拟其输入。显示上采用快照缓冲，以比最新快照晚约 0.08 秒的时间点在两份快照之间插值。绳子两端的力由双方位置共同决定，本地预测看到的对方位置有延迟，因此接绳时本地预测误差较大，由回滚校正修正；这是当前实现的已知限制。物理引擎约 630KB（压缩后）按需加载，加载完成前自己的小猫按快照显示。

大厅采用上下左右自由移动，角色彼此碰撞、可以互相挤开。

关卡移动参数来自素材包中的玩家移动配置：

- 按方向键时水平加速度 5000，最高水平速度 500（约 6 步达到），空中同样可以转向。松开按键站在地上会立即站住；在空中则保持原有速度。
- 跳跃是 1300 的向上速度，重力 3800，跳起约 220 高。跳跃按按键上升沿触发，持续按住不会自动连跳，离地后 0.2 秒内仍可起跳，另有 0.12 秒跳跃缓冲（后者为网页设定）。
- 挥荡、被绳子甩出时速度可以超过 500，按方向键不会把速度压回 500。
- 玩家之间不能互相推动：站着不动的小猫转为运动学刚体，其他人撞不动它；走到队友身边会停在旁边，不会把队友挤走。仍可以站在队友头上。

角色旋转锁定。输入按当前有效连接的到达顺序处理；浏览器重连后 sequence 从零开始仍能移动，旧连接有效性由房间服务校验。

地图数据中每个弹性绳对象连接 `PlayerObject1`、`PlayerObject2` 两个玩家刚体，配置为 `Distance=650`、端点偏移 `20,-40` 与 `-10,-40`、`CoeElastic=40`、`CoeElasticHor=30`、`CoeElasticUp=70`、三项阻尼 `0.2`。力学公式与质量换算仍在校准。网页当前在开局时随机队员顺序，再按该顺序形成相邻连接，是多人局的首版实现。网页只在拉长时沿两只小猫的连线施加等大反向拉力，大小为 `40 × 超出长度`，另按 `DamperElastic=0.2` 每步抵消两端沿绳方向相对速度的 20%；绳子不会推人，并保留最大加速度保护。站着的一端靠脚下固定住，被绳子横向拉扯超过 `FootJointForcePulling=3000` 时才会被拖动，向下的拉力只会把它压在地上。水平与向上分量的 `CoeElasticHor=30`、`CoeElasticUp=70` 两个系数的精确作用尚未确认，网页暂不使用；端点偏移只用于绘制。

出生点和间距为临时设定。关卡相机固定显示 1080 源单位的高度，标准宽度 2340（按屏幕宽高比左右延展），跟随自己的小猫，但不会越过地图边界：地图左右边界由地图数据的 `MapSize=8348.586` 算出（左边界 -1170），上下边界取平台范围。越过地图左右边界，或掉到地图底边以下 1500 时死亡；死亡回到复活点，网页暂用最近一次站稳的平台位置作为复活点。任意成员掉线会结束整局，服务端在对局中立即销毁模拟并把队伍送回大厅。钥匙绑定并跟随触发的玩家，任意队员都可携带；网页以单个 `keyOwnerId` 表示持有者，持有者接近出口时设置 `doorOpen`，随后沿用两人局的全员到达规则。普通星应计入拾取玩家，网页协议目前只记录已收集 ID，尚未同步归属。变化星可按钥匙/计时器重新激活，但 `InactiveTime=25` 的单位和触发时机未确认，网页暂不启用自动重激活。成员退出/返回大厅的队伍流程由服务端处理。

这些规则均为网页试玩实现。后续实现优先处理两人绳索边界、实际复活机制、钥匙/出口结束条件、星星归属和单向平台对象映射。

## 输入与生命周期

键盘使用 WASD/方向键，挑战中空格跳跃；鼠标点击地面会走向该点（到达、超时 8 秒或有其他输入时停止，挑战中只取水平方向）。大厅触屏同样点地面行走，按住拖动超过 12 像素时在按下处出现浮动摇杆，按拖动方向和幅度移动。挑战中触屏改用固定操控：左下方为左、右按钮和中间的水平摇杆，按住按钮全速移动，按住摇杆时按偏离中心的距离（30 像素满速）移动，按下位置偏离中心即立即转向；右下方为跳跃按钮，挑战中触摸场景本身不再移动。各按钮和摇杆按 pointer ID 独立跟踪，可多指并用。输入框、可编辑区域、对话框、窗口失焦和切换场景会清空运动输入。关闭组件释放 ResizeObserver、键盘/焦点监听、Pixi 场景和渲染器；共享素材缓存保留以避免重新进入时重复下载。加载失败显示可重试的中文错误，不使用替代角色或替代地图填充空画面。

`tests/game.test.ts` 使用准备好的真实地图验证固定步长一致性、两人绳索稳定、按住跳跃不连跳、死亡恢复、大厅移动与资源结构。运行测试前须完成资源准备。

## 仍待校准

绳端精确求解公式、多人连接拓扑、复活点坐标与延迟、钥匙消耗与通关时机、变化星计时单位以及单向平台映射，均不应由当前临时实现反推为既定规则。
